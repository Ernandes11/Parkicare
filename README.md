# ParkiCare

![Badge de Status](img.shields.io)

## 🌟 Objetivo do Projeto

O **ParkiCare** é um projeto com o objetivo geral de oferecer suporte abrangente a pessoas portadoras da doença de Parkinson. Nossa missão é promover a melhoria da qualidade de vida dos pacientes por meio de um sistema que permite o **monitoramento de sintomas**, **estímulo ao bem-estar** e **auxílio nas atividades da rotina diária**.

## 🧠 Relevância Acadêmica

Do ponto de vista acadêmico, o ParkiCare é um projeto de grande relevância, pois integra diversas áreas estudadas no Curso Técnico em Informática do [IFRN - Instituto Federal do Rio Grande do Norte](ifrn.edu.br):

*   **Programação:** Desenvolvimento da lógica de backend e funcionalidades interativas.
*   **Banco de Dados:** Modelagem e gerenciamento seguro das informações de saúde dos usuários.
*   **Desenvolvimento Web:** Criação da interface do usuário (frontend) responsiva e acessível.
*   **Design de Interfaces (UI/UX):** Foco na usabilidade e experiência do usuário, essencial para um público com necessidades específicas.
*   **Redes e Segurança:** Garantindo a comunicação eficiente e a proteção dos dados.
*   **Documentação de Sistemas:** Organização e registro de todo o processo de desenvolvimento.

O projeto permite a aplicação prática e consolidada dos conhecimentos teóricos adquiridos durante o curso.

## Instalação e Uso

Instruções básicas para rodar o projeto localmente.

1.  Clone o repositório:
    ```bash
    git clone (https://github.com/nicollyfagundes8/ParkiCare.git)
    ```
2.  Instale as dependências (exemplo para Node.js, ajuste conforme sua tecnologia):
    ```bash
    cd ParkiCare
    npm install
    ```
3.  Inicie o servidor (ajuste o comando de start):
    ```bash
    npm start
    ```
4.  Acesse `http://localhost:3000` no seu navegador.
